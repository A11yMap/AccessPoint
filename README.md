# **Access Point**

## **What is Access Point?**

AccessPoint is an easy, personalised way to view a place's accessibility status, with all the information you could need regarding a place's viability for YOU. It includes personalisation of ratings, user contributions to our information, further information, and a way for you to help improve our ever growing database of information, all to help the disabled, elderly, sick, and other people with accessibility needs.

## **Our Intentions**
AccessPoint is determined to provide individuals with functional disabilities, e.g. People in need of care, with an accessible map. This accessible map is determined to be the best map for the people in need of information regarding a place's accessibility. 

## **How to install**
Download the compressed folder below, extract and run the accessibility_map.html file.
